Como Usar o PIX4ME

Utilizar o PIX4ME é simples e rápido. A plataforma foi desenvolvida para permitir a criação de cobranças via PIX em poucos passos, sem exigir conhecimento técnico ou configurações avançadas.

Para iniciar, preencha o campo Chave Pix com a chave que receberá o pagamento. Você pode utilizar qualquer tipo de chave válida, como CPF, CNPJ, e-mail, número de telefone ou chave aleatória. Certifique-se de que a chave foi informada corretamente para evitar erros no pagamento.

Em seguida, informe o nome do Recebedor. Esse nome será exibido para quem for realizar o pagamento, ajudando na identificação correta da cobrança. Logo após, preencha o campo Cidade, respeitando o limite de caracteres solicitado pelo sistema.

No campo Valor, digite o valor que deseja cobrar, utilizando o formato indicado (por exemplo: 25,00). O sistema realizará a formatação automaticamente, garantindo compatibilidade com o padrão do PIX.

Após preencher todos os campos, clique no botão “Gerar cobrança”. O PIX4ME irá processar as informações e gerar automaticamente o QR Code de pagamento, além do código PIX em formato textual, que pode ser copiado e compartilhado.

O pagador poderá realizar o pagamento escaneando o QR Code com o aplicativo do banco ou copiando o código PIX e colando na área de pagamento do aplicativo bancário de sua preferência.

Durante a visualização da cobrança, o sistema exibirá um temporizador de expiração. Caso o tempo se esgote, será necessário gerar uma nova cobrança para garantir a validade das informações.

Para facilitar, o PIX4ME também disponibiliza um botão para copiar rapidamente o código PIX. Após o pagamento, basta gerar uma nova cobrança caso seja necessário realizar outro recebimento.

Seguindo esses passos, você poderá utilizar o PIX4ME de forma prática, segura e eficiente, simplificando o processo de recebimento de pagamentos via PIX no seu dia a dia.
